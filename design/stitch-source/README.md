# Stitch source

This directory preserves the design system, generated HTML, and reference
screens exported from the Stitch project used to design Reshoot.

To iterate on the original design through the Stitch MCP, read
[`STITCH_PROJECT.local.md`](./STITCH_PROJECT.local.md) for the project
reference. Use that existing project rather than creating a replacement.

The local reference file is intentionally excluded from Git. If it is missing,
find the project named **Reshoot AI Creative Studio** with the Stitch MCP and
recreate the local file with its project ID.
